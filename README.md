# Online Store Sales Data Analysis

## Project Overview
This project analyzes fictional online store sales data using Python. The purpose is to understand sales performance, profitability, product categories, and monthly sales trends.

## Objectives
- Analyze sales data using Python.
- Clean and organize the dataset.
- Calculate sales and profit metrics.
- Identify top-performing product categories.
- Visualize monthly sales trends.
- Generate useful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Google Colab

## Key Analysis
- Sales by Product Category
- Monthly Sales Trends
- Profit by Category
- Top 5 Products by Sales
- Key Performance Indicators (KPIs)

## Dataset
This project uses a fictional dataset generated for educational and portfolio purposes.

## Conclusion
This project demonstrates practical beginner-level data analysis skills, including data cleaning, exploratory data analysis, data visualization, and business insight generation.
