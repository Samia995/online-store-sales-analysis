# Online Store Sales Analysis

## Project Overview
This project analyzes online store sales data to identify sales trends, product performance, and business insights using Python.

## Objectives
- Analyze total sales and profit.
- Identify top-performing products.
- Understand sales trends.
- Explore customer purchasing patterns.
- Generate useful business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Business Insights

## Key Skills Demonstrated
- Data Analysis
- Data Cleaning
- Python Programming
- Data Visualization
- Analytical Thinking

## Conclusion
This beginner-level project helped me practice Python-based data analysis and understand how data can support business decisions.
